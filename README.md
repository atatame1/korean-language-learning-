# 韩语语法手册（日语对照版）

> **为「母语汉语 + 已会日语 + 有韩语基础」的学习者写的系统语法书。**
>
> 全书 20 章，按「韩语现象 → 日语对应 → 中文解释 → 例句 → 易错点」的固定结构展开。
> 目标不是"背规则"，而是**建立韩语的语法直觉**，并把你已有的日语能力变成加速器。

---

## 这本手册的特殊之处

市面上大多数韩语教材面向"零基础 + 只有汉语"的读者。你的条件不一样：

| 你的条件 | 意味着什么 |
|---|---|
| **母语汉语** | 汉字词是你的巨大优势（60% 词汇），但声调和语序会干扰 |
| **已会日语** | 语法结构几乎同构，**能省掉一半理解成本** |
| **有韩语基础语法** | 不需要从"这是主语"讲起，可以直接进难点 |

所以这本手册做了三件事：

1. **每个语法点都标了"日语对应"**，能迁移的你直接用，不能迁移的我标出来
2. **重点砸在日语没有的部分**：-(으)ㄹ 冠形词、-아/어 있다、은/는 的对比功能、敬语三层体系
3. **汉字词推导单独成章**（第 13 章），教你用日语反推韩语读音

## 怎么用这本手册

### 如果你是"已有基础，想系统补漏"

按这个顺序读（跳过你已会的）：

```
02 音变 → 05 은/는 vs 이/가 → 07 不规则活用
→ 10 定语形 → 12 依存名词 → 13 汉字词 → 19 被动与使动 → 14 误区
```

**这 8 章是韩语最难、最容易出错、也最能拉开水平差距的部分。**

### 如果你是"想从头系统过一遍"

按 01 → 18 顺序读，每章末尾有自测题（答案折叠在 `<details>` 里）。

### 如果你只想查某个点

用上面的目录表，或直接搜关键词。每章内部有编号小节（如 `5.2`），可以互相引用。

## 全书符号约定

| 符号 | 含义 |
|---|---|
| ✅ | 正确说法 |
| ❌ | 错误说法 |
| ⚠️ | 注意 / 例外 / 易错 |
| `[ ]` | 实际发音（如 국어 [구거]） |
| **粗体** | 关键概念 |
| → | 推导过程或对应关系 |
| ⇒ | 结论 |

**例句格式**：
```
韩语句子.           中文翻译。
```
对齐的部分是汉语解释。

## 三条最重要的提醒

### 1. 韩语的音变是"规则"，不是"例外"

第 02 章的七条规则能覆盖绝大多数情况。**不要背发音，要背规则然后推**。

### 2. 은/는 vs 이/가 靠"信息结构"判断，不靠语感

第 05 章给了四条可操作标准（新/旧信息、焦点位置、大小主语、对比语境）。**每次选助词都过一遍这四条**，200 句之后就是条件反射。

### 3. 日语是脚手架，不是答案

日语能帮你理解 70% 的韩语语法，但剩下 30% 恰恰是"说地道"的关键：
- -(으)ㄹ 冠形词（未来）
- -아/어 있다（状态 vs 进行）
- 은/는 的对比功能
- 敬语的三层独立性

**这四点必须当全新知识学，不能从日语推。**

## 修订记录（第二版）

第一稿写完后通读复查，修正了以下问题，如果你已经读过旧版，重点看这几处：

**改了 8 处硬错误**

| 位置 | 原稿问题 | 修正 |
|---|---|---|
| 02 §2.2.1 | 说"ㄴ/ㅁ 收音不触发紧音化"，举了 담다[담다]、삼다[삼다] | **错**。词干 ㄴ/ㅁ + 词尾 ㄱㄷㅅㅈ 要变紧音（담다[담따]、안고[안꼬]、앉습니다[안씀니다]），只有名词内部不触发 |
| 02 §2.3.3 | 먹습니다 的推导把 ㅂ+ㅅ 当紧音化 | **搞错了相邻关系**。是 ㄱ(收音)+ㅅ(初声)→ㅆ，再 ㅂ(收音)+ㄴ(初声)→ㅁ |
| 06 §6.4 | 이다 活用表把 학생标成"无收音" | 表头和示例全错位，已改为「有收音（학생）/ 无收音（커피）」 |
| 06 §6.7 | 하 + 여 → ㅒ | 应为 **ㅐ** |
| 07 §7.7 | 러 不规则写成 이르다→이러、푸르다→푸러 | **错**。ㅡ 不脱落：**이르러、푸르러**（比看起来多一个音节） |
| 07 开头 | "只有 8 类" | 实为 **9 类**（ㅅㄷㅂㅎ르러우ㅡㄹ） |
| 07 §7.4 | "动词里 돕다·곱다·굽다 三个不规则" | 곱다 是形容词；动词不止两个（见第三版修订） |
| 10 §10.3 | "形容词没有 -(으)ㄹ 冠形词" | **错**。形容词的 -(으)ㄹ 表**推测**（좋을 것 같다），只是不表"未来计划" |
| 11 §11.9 | 客体敬语表把 받다→받으시다 归为客体 | 받으시다 是**主体敬语**，已重组表格并区分谦让/尊敬两种机制 |
| 12 §12.8 | "错误 4"整段重复了两遍 | 已删，另补"错误 7：때문 前接 -는" |
| 13 §13.3 / §13.6 | 残留"일서? → 실제 일치?"、"北 북/배（敗北? 不…）" | 已清理，多音字例换成 金/不/樂/宅/率 |

**补了 3 处内容**

1. **新增第 19 章「被动与使动」**——原稿完全没有覆盖，这是最严重的结构性缺口。含 -이/히/리/기 的被动与使动**同形歧义**判别法、되다/받다/당하다 三分、以及日语「迷惑の受身」为什么在韩语里不成立。
2. **04 §4.5 补「에 的五个扩展」**——에 대해(서)、에 대한、에 따라、에 비해、에 의하면，原稿一个都没写。
3. **12 §12.3 补「탓 / 덕분 / 바람에 / 통에 / 마련이다」**——때문 的中性因果只写了一半，缺了"怪罪/归功/突发"这一整组。

**清理了 5 处残留**

02 章的"실례?""젊지?"、06 章的"좋이? ❌ / 깨끗히? ❌"、12 章重复段、13 章的"?"式自问自答，全部删除或改写。另把 02 §2.10 的"特殊读音表"从"잠깐만[잠깐만]"这类无用条目换成了双收音代表音、ㄴ 添加、送气三类真正需要硬记的词。

## 修订记录（第三版）

第二版之后又对着韩国「标准发音法」原文和几本语法书逐条核了一遍，改了 5 处，补了 2 块。

**改了 5 处**

| 位置 | 原稿问题 | 修正 |
|---|---|---|
| 07 §7.4 | "ㅂ 不规则动词只有 돕다、굽다" | **漏了三个高频词**：**눕다 → 누워**、**줍다 → 주워**、**깁다 → 기워**。已改为五个动词的清单，并删掉"看到 ㅂ 动词默认规则"这句危险建议 |
| 07 §7.4 | 把 굽다 说成"ㅂ 前是 ㅗ"，并用"元音和谐"解释 도와 | 굽 的元音是 **ㅜ**；更关键的是 **ㅂ 不规则一律接 -어**（가깝다→가까워、고맙다→고마워），所以不能按和谐推。已改为"ㅂ→우 + -어→워，只有 돕다/곱다 接 -아 变 와" |
| 04 §4.1 | "❌ 누구는 / ❌ 무엇은" | 누구는 **不是错**，它是主题形（누구는 밥 먹고 누구는…）。真正的规则是"作主语必须用 누가，没有 누구가" |
| 04 §4.10 | 用 ❌ 标出 `나는 너보다 커요`，又说是对的 | 自相矛盾。已改为正面说明"这句是对的，错的是 보다 接 를" |
| 19 §19.1.4 | "방이 조용해졌다? ✅ 可以"、"문이 열려졌다？❌" | 草稿式自问自答，读着像没定论。已改成明确结论：形容词用 -아/어지다（조용해졌어요），열리다 本身是被动不能再加 -지다 |

**补了 2 块**

1. **08 §8.8 否定整节重写**——原来只有 안/못/-지 않다 四小节。现在是 13 个小节：하다 动词的"三明治"位置、**못하다（不擅长）vs 못 하다（不能做）的空格区别**、形容词不能接 못、固有否定词（있다→없다／알다→모르다／이다→아니다）、命令否定 -지 말다、**义务/许可/禁止五件套**、双重否定、否定极性词（아무도·전혀·별로 必须配否定），并补了 5 道练习。
2. **02 §2.2.1 补一个反直觉例外**——由**被动/使动**派生的词干不触发 ㄴ/ㅁ 紧音化：안고 读 [안꼬]，但 안기다 读 [안기다]。另在 15 章补了"数量 ≥100 必须换汉字数词"（두 명 → 백 명）。
